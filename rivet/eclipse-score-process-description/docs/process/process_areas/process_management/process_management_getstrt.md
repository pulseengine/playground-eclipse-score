# Getting Started

### Getting Started on Process Management

{{artifact:DOC_GETSTRT__PROCESS_MANAGEMENT:status,safety-level,security}}

This document describes the steps to create and maintain the process strategy and the
process description.

Therefore a guideline [[GD_GUIDL__PROCESS_MANAGEMENT]] and
a concept [[DOC_CONCEPT__PROCESS_MANAGEMENT]] are available.

# General Workflow

The workflows are defined in the process_management_workflows section.

For every change identified, the following workflows are executed:

* Create and maintain process management strategy according to [[WF__CR_MT_PROCESS_MGT_STRATEGY]]
* Define and approves process description according to [[WF__DEF_APP_PROCESS_DESCRIPTION]]
* Monitor and improve process implementation and trigger improvements according  [[WF__MON_IMP_PROCESS_DESCRIPTION]]
