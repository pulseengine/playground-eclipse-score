# Getting Started

### Architecture Design Process

{{artifact:DOC_GETSTRT__ARCH_PROCESS:status,safety-level,security}}

This document describes the steps to create the architectural design of a system. It provides an overview of the necessary activities and their sequence to effectively design both the feature architecture and the component architecture.

As described in the Architecture Design Concept <architectural_viewpoints>, this page provides an overview of the steps required to create the feature architecture and the component architecture. For detailed descriptions, see Architecture Design Guideline <gd_guidl__arch_design> and Architecture Design Process <doc_concept__arch_process>.
